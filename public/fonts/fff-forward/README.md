# FFF Forward

FFF Forward Regular by Fonts For Flash (FFF Web Media Inc.).

- Source: https://www.1001fonts.com/fff-forward-font.html
- Download: https://www.1001fonts.com/download/fff-forward.zip
- The original `FFFFORWA.TTF` is included unchanged as `fff-forward.ttf`.
- `LICENSE.txt` preserves the vendor's accompanying license.

The wya.im maintainer clarified on 2026-10-24 that no separate webfont
redistribution permission has been obtained. The vendor's license permits use in
website projects but also restricts redistribution of the font file; its scope
for self-hosted webfonts has not been confirmed. The current implementation
serves the TTF to visitors through `@font-face`, and committing this asset to a
public repository would also make the font file available for download.

This font remains a third-party asset under its vendor's terms; the application's
license does not grant additional rights to the font.
